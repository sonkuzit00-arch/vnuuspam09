## 4. Что уже работает в приложении

- **Обращения:** регистрация (поле «Тема письма по регламенту» само заполняет форму), карточка с номером `ОГ-N`, редактирование карточки, история, файлы, удаление (только администратор, по одному и «Удалить все» вверху раздела «Пользователи»).
- **Маршрутизация КАУ**, формат отработки, «Куда направлено» (подсказки из книжки контактов ОГВ), категория.
- **Этапы ДЗ:** согласовано ДГД → подписано депутатом → направлено. Без ОГВ и обоснования не направить; ДЗ губернатору Воронежской области запрещён.
- **Приоритетные регионы** (Воронеж, Липецк, Калуга, Тамбов, Курск) — метка, всегда сверху. **Массовые** — отметка + подсказка «похоже на массовое» и правило регламента.
- **Поручения** со сроком; отметка «выполнено за исполнителя» со способом (по почте и т.д.); «Вернуть в работу».
- **Ход согласования:** этапы за любого участника (кто, кому, когда, способ, комментарий), с правкой и удалением.
- **Почта:** импорт из папки `Обращения` → черновик, видит только Кузнецова → «Принять» / «Отклонить». Тема по регламенту заполняет поля; письма с `[ОГ-N]` и «Взамен ранее направленного» прикрепляются к карточке. Копия нового обращения на `APPEALS_EMAIL_TO` с темой по регламенту.
- **Уведомления** (почта/Telegram, каждый настраивает в профиле), напоминания о сроках.
- **Отчёты:** по месяцам, положительные результаты, благодарности; ключевые показатели (поступило, отработано, просрочено, % в срок, % положительных, среднее/медиана дней, часы до маршрутизации, ДЗ, ответы ОГВ); разрезы по темам, регионам, каналам, форматам, сотрудникам; Excel / PDF / CSV / «На почту»; ежедневный журнал руководителям.
- **Пользователи:** создание, роли, сброс пароля, блокировка; профиль со сменой пароля.
- **Книжка контактов ОГВ** и **реестр подарков** (сделаны в другом чате).

## 6. Процесс (по модели и уточнениям Софьи)

- **Каналы:** САДД (уже зарегистрировано → сразу КАУ); почта и эл. почта (Кузнецова регистрирует в САДД, № `гр-ЧСВ-5/номер`, для почты дата по штемпелю); соцсети (Сибирко; комментарии в отчёт ЦУР); сайт ОП (юристы ОП); приёмы и поездки (Ковешникова; Боровкова передаёт ей); звонки в приёмную (направляем подать официальное обращение).
- **КАУ:** проверка дублей → формат → ответственные → контроль. Форматы: ДЗ напрямую / с проработкой GR, типовой ответ, депутату по территории, пересылка в комитет, позиция комитета, СВО, законотворчество, юр. консультация (ОП), в работу ОП, БФ, BTL, приглашение на мероприятие, гуманитарная помощь СВО.
- **Проработка** — только для нетиповых (Ковешникова, срок 3 дня, концепцию согласует Чижов). Типовые: Ковешникова сразу ставит ТЗ на ДЗ Кузнецовой/Сибирко, или КАУ напрямую ставит ДЗ Кузнецовой.
- **ДЗ:** пишут всегда Кузнецова/Сибирко → (Ковешникова согласует при GR) → Чижов → подпись лично депутатом → **звонок в ОГВ** (разъяснить, предупредить; звонит ответственный за проработку) → направить, промежуточный ответ гражданину → ждём 30 дней → нет ответа: КАУ назначает ответственного за выяснение (звонок по базе контактов, повторный запрос, вышестоящий) → положительный: благодарность ОГВ, ответ гражданину, Боровкова решает об освещении, КАУ назначает ответственного за **получение благодарности** (видео в приоритете).
- **Перенаправление:** только депутатам ЕР, звонок помощникам за согласием, если уже в связках САДД — не пересылаем, внутренний бланк с реестром передачи, 5 дней.
- **СВО — тег, не отдельный процесс:** запросы Уполномоченному и Цивилевой без согласования ДГД; боец в плену → ДГД Саралиев (списки на обмен); ответ гражданину с просьбой прислать ответы; плен подтверждён → повторно Саралиеву.
- **Сроки:** ответ 7 рабочих дней (внутренний), перенаправление 5 дней, 59-ФЗ — 30 дней с продлением, ответ ОГВ на ДЗ — 30 дней. Штраф за нарушение 5–10 тыс. ₽.
- **Прочее из регламента:** массовые (>5) не нашей территории — не отвечаем, приоритетных регионов — обязательно; ДЗ на губернатора ВО — нельзя; e-mail без официального обращения → запросить скан; контрольные обращения фракции ЕР → в ОП с пометкой, отчёт в САДД; «Жизненно важное» → личный контроль GR; ошибка → письмо «Взамен ранее направленного».
- **Тема письма (регламент):** `ГД; САДД / Почта / Электронная почта; Регион; ФИО; дата поступления-крайняя дата; Проблема` (+ `(коллективное обращение)`); тело: `Дата – форма поступления – поступило обращение от ФИО – с просьбой о содействии в – суть`, «В связках N депутатов ГД».
